# CodeCash web

React 19 + Router 7 + Ant Design 6 + TanStack Query + i18next. Shared UI lives in packages/ui; API client lives in packages/api-client.

Run `pnpm dev` from the repository root so the API and Vite start together. Vite proxies /api to port 3000. See the root README for accounts, storage modes, tests and limitations.
